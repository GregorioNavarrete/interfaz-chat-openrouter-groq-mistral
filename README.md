# Chat multimodelo

1. `npm install` y `npm start`, luego abrir http://localhost:3000 (también funciona abriendo `public/index.html`).
2. En «Claves y apariencia» pegar la clave de OpenRouter, Groq o Mistral. Por defecto se borra al cerrar la pestaña.
3. Elegir modelo (botón de arriba), escribir y enviar. Cada sesión recuerda su propio modelo.
